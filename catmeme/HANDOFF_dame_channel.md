## ショートの作り方（これを使う）
- **ひな形：`short_dame_template.py`**（`short_refstyle.py` と同じ見た目・動き）。コピーして台本の部分だけ書き換える
- 見た目（参考ショートのマネ）
  - 背景イラストを縦いっぱいに敷き、**ゆっくり動かし続ける**（寄り引き＋左右上下）
  - 上に黒い帯の2行タイトル（1行目：赤い大きな文字、2行目：黄色）
  - 猫ミームは画面の下半分に大きく1〜2匹。**元の音を鳴らす**（しゃべる猫だけ）
  - セリフは帯のすぐ下、白か黄緑の太い文字＋黒い太縁。強調語だけ赤（台本で `*ここ*`）
  - 相手役は足元に黄緑の大きな文字で役名
  - **登場人物（相手役）にするのは生き物だけ**（例：大家さん・あの馬・店員・友だち）。お金（「残り3千円」など）・口座・「競馬」のような物や出来事は登場人物にしない（猫ミームに役名を付けて立たせない。セリフの文字で見せる）
  - 掛け合い（相手役）はできるだけ増やす。競馬のレース中は走る動物のミームを「馬」として右から左へ走らせる（`short_dame_rent.py` の `race()`）
  - 上の帯の1行目は「とあるダメ人間」（「の」は付けない）。最後に「ダメ人間」の字幕は出さない
  - **同じ猫ミームが続くカットは登場し直さない**（続きから動く・位置が変われば滑らかに移動）
  - 1セリフ2〜3秒のテンポ
- 長さ：**45〜58秒**（範囲外だと書き出しが止まる。ユーザーが許可したときだけ例外）
- 書き出し後：`out/<名前>_preview/` で全カットを並べて確認 → 720p版（30MB未満）を送る → 1080p版を `release/` に入れて GitHub のリンクを伝える
- 別案：最初の5秒を派手にする「A＋Dのつかみ」（`short_hooks.py` の `hook_cut_AD`）も使える

  赤黄の集中線、金額などは封筒・爆発バッジで（猫ミームに重ねない）、猫ミーム。話ごとに関数を足す（#1 は `dame_rent()`）

## ユーザーとのやりとりのルール（前のセッションから）
- 返事は日本語・やさしい言葉で（専門用語を使わない）
- 書き出しは「作り直して」などと言われたときに行う
- 変更のたびにコミットして push（`git push -u origin <ブランチ>`）
- 環境変数の GEMINI_API_KEY の値は**絶対に表示しない**
- AIで作った部分（背景イラストなど）がある場合は概要欄などで表示する
- 語尾に「にゃ」は使わない。くだけた口調
- 同じ猫ミームの使い回しは、1本の中で多すぎないように（前のチャンネルは「3回まで・2場面あける」）
- 実在の人物・会社をバカにしない（ダメ人間は架空のキャラとして演じる）
