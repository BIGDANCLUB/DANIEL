# 猫ミーム長時間動画

横長（1920x1080）・数分〜十数分の YouTube 動画を作ります。猫ミーム素材は `assets/` に置きます。

## レギュラーの猫（全動画共通）
- **ニュース猫** … 視聴者の代わり。驚く・キレる・ツッコむ。画面の左に大きく、役名の札「ニュース猫」
- **博識な猫** … 説明役。冷静に答えてツッコミ返す。画面の右に大きく、役名の札「博識な猫」（旧名「物知り猫」）
- どちらも口調はくだけた感じ。語尾に「にゃ」は使わない

## 素材のルール
- 猫ミーム素材（`assets/`）は、動画をまたいでも、1本の中でも使い回してよい（ショートの「使い回し禁止」はここでは適用しない）
- ただし同じ素材ばかりにならないようにする
  - 1本の中で同じ素材を使うのは **3回まで**
  - 同じ素材を **続けて使わない**（間に別の素材を2つ以上はさむ）
  - 1本の中で、1つの素材が全体の出番の **2割を超えない**
- 同じ素材を再び使うときは、反転・拡大・切り出す範囲などを変えて、見え方を少し変える

## 画面部品（背景イラスト以外）
- `parts.py` … 字幕枠・吹き出し・名前テロップ・解説カード（箇条書き／棒グラフ／流れ図／大きな文字）を描く共通の関数。すべて 1920x1080 の透過PNG
  - ナレーション字幕は画面下の紺の帯、猫のセリフは白い吹き出し（上に役名の札）
  - 解説カードは画面左上〜中央。右下（`CAT_SLOT`）は小さい猫を置く場所として空けてある
  - フォントは M PLUS Rounded 1c（初回に自動ダウンロード、`fonts/` はコミットしない）
- 動画ごとのスクリプト（例: `make_parts_01_todai.py`）で `parts/<動画>/` に書き出す。`preview/` は仮背景に重ねた確認用

## 動画の書き出し
- `render.py` … カットの並びから動画を作る共通の仕組み。猫ミームの緑を自動で抜き（色は素材ごとに自動判定）、背景 → 猫 → 部品の順に重ね、BGM・効果音を混ぜて mp4 にする
  - 体の途中で切れている素材は画面の下の辺から生やし、全身の素材は床（`bottom`）に立たせる
  - 猫ミーム素材の元の音は使わない。効果音（ポン・ドン・ドラムロール・チリン）は合成
- 動画ごとのカット割りは `cuts_<動画>.py`。例: `python3 catmeme/cuts_01_todai.py` → `catmeme/out/`（コミットしない）

## 素材の流し方（全動画共通）
- `assets/play.json` … 素材ごとに「最後まで流す（full）」「何秒で切る（until）」を決めておくファイル
  - 書き出し時、その素材を大きく出すカットは自動でこの長さになる（解説カード右下の小さい猫・止め絵は対象外）
  - 例：ハッピー猫は7秒、マックスウェル猫・チピチピ猫は6秒、ヤギと猫は3秒（「はぁ？」まで）、困惑する猫・絶望する子猫・怒る猫と怒られる猫は最後まで
  - 新しく指定が出たら、このファイルに1行足す
