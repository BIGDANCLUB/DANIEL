# 猫ミーム長時間動画

横長（1920x1080）・数分〜十数分の YouTube 動画を作ります。猫ミーム素材は `assets/` に置きます。

## 素材のルール
- 猫ミーム素材（`assets/`）は、動画をまたいでも、1本の中でも使い回してよい（ショートの「使い回し禁止」はここでは適用しない）
- ただし同じ素材ばかりにならないようにする
  - 1本の中で同じ素材を使うのは **3回まで**
  - 同じ素材を **続けて使わない**（間に別の素材を2つ以上はさむ）
  - 1本の中で、1つの素材が全体の出番の **2割を超えない**
- 同じ素材を再び使うときは、反転・拡大・切り出す範囲などを変えて、見え方を少し変える

## 画面部品（背景イラスト以外）
- `parts.py` … 字幕枠・吹き出し・名前テロップ・解説カード（箇条書き／棒グラフ／流れ図／大きな文字）を描く共通の関数。すべて 1920x1080 の透過PNG
  - ナレーション字幕は画面下の紺の帯、猫のセリフは白い吹き出し（上に役名の札）
  - 解説カードは画面左上〜中央。右下（`CAT_SLOT`）は小さい猫を置く場所として空けてある
  - フォントは M PLUS Rounded 1c（初回に自動ダウンロード、`fonts/` はコミットしない）
- 動画ごとのスクリプト（例: `make_parts_01_todai.py`）で `parts/<動画>/` に書き出す。`preview/` は仮背景に重ねた確認用
