# 猫ミーム長時間動画

横長（1920x1080）・数分〜十数分の YouTube 動画を作ります。猫ミーム素材は `assets/` に置きます。

## やりとりのルール（10/14 ユーザー指定）
- **ユーザーへの返事は必ず日本語**で書く（途中経過の短い報告も日本語）

## レギュラーの猫（全動画共通）
- **ニュース猫** … 視聴者の代わり。驚く・キレる・ツッコむ。画面の左に大きく、役名の札「ニュース猫」
- **博識な猫** … 説明役。冷静に答えてツッコミ返す。画面の右に大きく、役名の札「博識な猫」（旧名「物知り猫」）
- どちらも口調はくだけた感じ。語尾に「にゃ」は使わない

## 冒頭の注意書き（全動画共通・10/12 ユーザー指定）
- 注意書きテロップの**一番最後に「今日の一言」を1行**足す。指定があればその文、なければ日常のゆるい一言を毎回考える
  - 例：「※編集中お腹が極度に減っています」「※今日は猫カフェはしごしました」「※今日はクレーンゲームで1万円かけてハイチュウを取りました」
- 「これ、納得できますか？」などの問いかけは、**原稿やユーザーが指定した所にだけ**入れる。こちらから冒頭などに足さない（10/13 ユーザー指定）

## ショートの概要欄（10/12 ユーザー指定）
- タイトルと同じ文の下に、2行目で本編のURLを貼る：`▶ くわしくは本編で：https://youtu.be/…`
- ショートの概要欄のURLは押せない（文字だけ）ので、YouTube Studio のショートの「関連動画」にも本編を設定する

## サムネのフォーマット（10/13 ユーザー指定。参考サムネを構成・文字・大きさまでマネする）
- ショート：`make_thumb_short_ref.py`（上に黒い帯＋2行の極太文字を横いっぱい・1行8〜10文字・2行で色を変える／下は写真を全面＋猫ミームを入れ込む／ひとことテロップ1つ）
- **長尺は固定の3パターン。サムネを作るときは毎回この3つ（A・B・C）を全部作って提案する**（10/13 ユーザー指定）。見本は `reference/thumb_patterns/long_A〜C.png`（12本目）、作り方は `make_thumb_long_ref.py` の `type_a / type_b / type_c`
  - A：上に写真2枚（左にアップの猫）＋左下に白い札（赤い文字・少し傾ける）／下は黄色の地に黒の極太2行（大事な言葉を青・赤に）
  - B：写真4枚を横に並べ、赤い矢印と黄色の書き文字で中を指す／下は白→黄のグラデーションに赤1行＋紺1行
  - C：写真全面に猫ミーム／上の端の黒い帯に黄色い小さめの1行／下に黄色グラデーションの超巨大1行（黒い太縁）
- **ショート本編の上の帯もサムネと同じ作り**（画面の一番上から黒い帯・2行の極太文字を横いっぱい・スマホで切れない幅）。`short_refstyle.title_band(上の行, 下の行, 上の色, 下の色, 上の縁の色)`（10/13 ユーザー指定）
- **ショートの最初の効果音は「チリン」（`se/short_start_chirin.mp3`）**。`short_refstyle.keep_going()` で自動で入る（10/13 ユーザー指定）
- ショートのセリフは大きめ（指定の1.3倍、横幅に収まらない分は少し細くして大きさを保つ）
- 写真はユーザーが用意する（ないときは背景イラストで代用）。右下は再生時間で隠れるので大事な文字を置かない

## 動画素材（動く背景・10/13 ユーザー指定）
- `assets_video/wide`（横動画用）と `assets_video/tall`（ショート用）。**向きに合ったものを使う**。一覧は `assets_video/README.md`
- 長尺・ショートとも、合う場面では静止画の背景の代わりに積極的に使う

## 最後の画面（全動画共通・10/12 ユーザー指定）
- 「→ ○本目もどうぞ」の画面は使わない。代わりに **「チャンネル登録よろしく！」の画面**（`parts/common/subscribe.png`・`make_parts_common.py`）で終わる
- **「以前の動画で述べた」「○本目で見た」など、過去の動画にふれるセリフ・字幕は一切入れない**（10/13 ユーザー指定）
- **下の黒い字幕帯（説明モード）に猫素材をかぶせない**。猫は帯の上に収める（役名札は帯にかかってもよい）。`render.EXPLAIN_TOP` より上に自動で置く（10/14 ユーザー指定）
- **主語になる団体（県・税関・警察庁・県警など）が何かをした場面では、その団体を猫素材にして役名札（団体名）つきで登場させる**（10/14 ユーザー指定・例：cuts_13_yard の org()）
- **ユーザーが渡した写真の背景は、ゆっくり横・縦に動かして動画っぽくする**（10/14 ユーザー指定・`render.pan_mode`）
- **曲つきの猫素材（CATALOG.md の ⚠）は、同じカットに2つ入れない**（BGMが2つ鳴るため）。`cuts_04_leak.allocate` が自動でよける（10/13 ユーザー指定）
- 数字は「何の数か」が分かる書き方にする（例：全国の数ではなく「このヤードが受け取ったとみられる数」）。「国の法律がない」も「ヤードを取り締まる国の法律がない」のように対象を書く

## 字幕の改行（全動画共通・10/12 ユーザー指定）
- 単語の途中で改行しない（「子ども食堂」「総額 約2億5,000万円」などが2行に分かれないように）。長い字幕は自分で `\n` を入れて、区切りのいい所で改行する

## 素材のルール
- 猫ミーム素材（`assets/`）は、動画をまたいでも、1本の中でも使い回してよい（ショートの「使い回し禁止」はここでは適用しない）
- ショートは **45秒以上58秒以内**（`short_03_kodomo_nisa.py` の `run()` が範囲外なら止める）
- ショートのサムネは、何のニュースか一目でわかる帯（例：「個人情報流出」）を一番上に入れる
- ただし同じ素材ばかりにならないようにする
  - 1本の中で同じ素材を使うのは **3回まで**
  - 同じ素材を **続けて使わない**（間に別の素材を2つ以上はさむ）
  - 1本の中で、1つの素材が全体の出番の **2割を超えない**
- 同じ素材を再び使うときは、反転・拡大・切り出す範囲などを変えて、見え方を少し変える

## 画面部品（背景イラスト以外）
- `parts.py` … 字幕枠・吹き出し・名前テロップ・解説カード（箇条書き／棒グラフ／流れ図／大きな文字）を描く共通の関数。すべて 1920x1080 の透過PNG
  - ナレーション字幕は画面下の紺の帯、猫のセリフは白い吹き出し（上に役名の札）
  - 解説カードは画面左上〜中央。右下（`CAT_SLOT`）は小さい猫を置く場所として空けてある
  - フォントは M PLUS Rounded 1c（初回に自動ダウンロード、`fonts/` はコミットしない）
- 動画ごとのスクリプト（例: `make_parts_01_todai.py`）で `parts/<動画>/` に書き出す。`preview/` は仮背景に重ねた確認用

## 動画の書き出し
- `render.py` … カットの並びから動画を作る共通の仕組み。猫ミームの緑を自動で抜き（色は素材ごとに自動判定）、背景 → 猫 → 部品の順に重ね、BGM・効果音を混ぜて mp4 にする
  - 体の途中で切れている素材は画面の下の辺から生やし、全身の素材は床（`bottom`）に立たせる
  - 猫ミーム素材の元の音は使わない。効果音（ポン・ドン・ドラムロール・チリン）は合成
- 動画ごとのカット割りは `cuts_<動画>.py`。例: `python3 catmeme/cuts_01_todai.py` → `catmeme/out/`（コミットしない）

## 素材の流し方（全動画共通）
- `assets/play.json` … 素材ごとに「最後まで流す（full）」「何秒で切る（until）」を決めておくファイル
  - 書き出し時、その素材を大きく出すカットは自動でこの長さになる（解説カード右下の小さい猫・止め絵は対象外）
  - 例：ハッピー猫は7秒、マックスウェル猫・チピチピ猫は6秒、ヤギと猫は3秒（「はぁ？」まで）、困惑する猫・絶望する子猫・怒る猫と怒られる猫は最後まで
  - 新しく指定が出たら、このファイルに1行足す

## YouTube のタイトル・説明文（全動画共通）
- `scripts/<動画>_youtube.md` に置く
- 説明文には **参考にした情報（出典のリンク）は入れない**。出典は原稿（`scripts/<動画>.md`）の最後に残しておく
- 説明文に入れるもの: あらすじ2〜3行、コメントのお願い、目次（時間つき）、ご注意（猫は演出・人物の言葉は「報道をもとに意味を変えずにまとめたように配慮しております」・AI生成）、BGM・効果音のクレジット

## 参考動画ふうの作り（03 から）
- 猫2匹の掛け合い・色つき役名札・赤い強調文字＋集中線・図の差し込み・説明モード・黒い区切り画面（詳しくは render.py の冒頭）
- 「とある証券会社の窓口」のような**場所の字幕（左上の地名）は使わない**
