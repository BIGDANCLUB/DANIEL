# 棒グラフ比較ショートの作り方（完成形：short_33_chiiki.py「東京・大阪・地方」・10/27 ユーザー確定）

新しく棒グラフで比べるショートを作るときは、この決まりに全部したがう。部品は `bars_short.py`（描画）と `bars_auto.py`（台本の組み立て）。

## 長さ・音
- 厳密に 59.9 秒（`bars_auto.build` が全体をのばして合わせる）。BGM なし。猫の声と効果音だけ
- 重りが落ちる音：explosion_chudoon。結果発表：game_mario_1up。最後のマイナス（プラス）表示：gong_dora_jaan（じゃーん）

## 見た目
- `style="bright"`：白〜水色のすりガラスのパネル＋水色の細い枠。棒は黄色を使わない（他チャンネルと被るため）
  - 残りのお金：ミントグリーンのグラデーション＋うすい斜めじま
  - 差し引く項目：明るい青・紫・オレンジ・コーラルのグラデーション、白い字。金額どおりの長さ（最低の高さは付けない）
- タイトル（上の2行）：1行目 赤、2行目 青（白いふち）
- 3列のとき：棒は短め（下端 y=990）、猫は棒の下に大きく（少し棒にかかってよい）。2列のとき：猫は棒の外側
- 重りの文字が長いときは2行にする（`wlabel`）。例「自動車\n交通費」

## 構成（上から順番）
1. **冒頭**：3列とも同じ素材の猫を3匹、大きく（例：叫ぶマーモット高速版、踊りまわるマクスウェル猫）。字幕なし。3匹とも鳴らす（`voice=(0, 1, 2)`）
   - 画面の上半分に**タイトルコール**（赤い角丸の板・白いふち・少し傾ける・ドンと縮んで出る）。
     上の帯のタイトルとは**ちがう言葉**にする（例「住むならどこがおトク？／都会vs地方 お金バトル」）
2. つかみのセリフ 2〜3つ（「みんな○○！」→「○○だから勝ちでしょ？」→「……本当に？」はぁ？猫を大きく）
3. **項目ごと**に：重りが落ちる（衝撃波：白い光→うすい黄色＋黒ふちの輪が2重に広がる＋放射線）→ 棒がのびる → セリフ1〜2つ
   - 重りの場面の猫は**3匹とも同じ素材**。順番に 戸惑う猫 → 目を見開くキジトラ → 戸惑う猫 → いじける猫 → 戸惑う猫 → 驚く猫（楽しそうな素材は使わない）
4. **結果発表**（重りではない）：暗転 → スポットライト2本 → 黒い帯に金色の「結果発表」→ 紙吹雪。1UP の音
5. 結果のセリフ 2〜3つ（1つ目は緑の枠の白い箱）
6. **最後**：画面いっぱいに「○○は 毎月 −○万円」（赤い集中線・リアルなお札が降る・揺れ）＋小さい1行。
   よい結果を言うときは `"good"` で金色・緑（例「実家暮らしは 毎月 +8.3万円」）

## 猫の使い方
- **どの場面も猫は列の数だけ出す**（空いた列は聞き役の猫で自動でうめる）
- しゃべる側の猫だけ鳴らす。両方鳴らすときは `voice=(0, 2)` のように
- 気持ちに合わせて選ぶ：負けた側は泣く（バナナ猫・嘆く子猫）、そこまで悲しくない側はぼーっとする猫、勝った側は踊る
- 同じ素材を前の場面と続けて使わない（冒頭と重りの場面の「3匹そろえ」は別）
- 掛け声を出したいときは5つ目に文字（例「もっと入れろや」→ ＼もっと入れろや／）

## 概要欄
- タイトル1行＋ハッシュタグ。数字の目安があるときだけ「※…ざっくりの目安です」を1行
