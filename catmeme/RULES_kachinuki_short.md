# 勝ち抜きシリーズ（ショート）の作り方
- **最新の手本：short_148_zangyo_gyokai.py「業界別残業時間 勝ち抜きバトル」（11/25 ユーザー確定）**。新しく作るときは 148 をひな形にする
- 初代の完成形：short_143_gyokai_nenshu.py「業界別平均年収 勝ち抜きバトル」（11/24）

## 148 で決まったこと（143 より新しいルール・こちらを優先）
- 比べ方は **1対1だけ**（前の勝者が左・新しい項目が右）。比べる回数を増やして 59.9 秒にする（足りないときは「全体平均」など同じ調査の値を足す）
- 「うちの業界〜」の問いかけ場面はなし。冒頭は流れるランキング＋**危険の帯**（黄色と黒の斜めじまが流れる・横いっぱい・画面のまん中寄り・猫に少しかかってよい）
  - 帯の中：1行目 白「業界別！」・2行目 黄「○○バトル」の極太字。左右に注意の三角マーク、上下に「! WARNING !」が 0.25 秒ごとに点滅
  - 帯の音：映画風ドーン＋ゴゴゴゴ＋サイレン。帯が消えるところでフェードアウト。右はしで1秒止まった瞬間にファンファーレ
- 横流しは速め（約6.5秒）。余った時間は勝ち負けの場面に足す
- 棒の起点は少し上（BAR_BASE 1225）。下の白い札を高くして、項目名・数字を大きく
- 次の比べに移るとき、前の勝者は **棒・札・猫ごと 0.7 秒で右から左へスッと動く**（札の色はふつうに戻してから）。動き終わってから新しい項目が出てのびる
- 勝ち負けの字幕ボックス：勝ち＝上のほう（y 590）・負け＝y 770。猫にかからない位置
- 同じ値なら「引き分け」（両方赤・両方のセリフ）
- 題材によっては勝った側を悲しませてもよい（残業のように「多いほどつらい」もの）
- 単位は題材に合わせる（unit_fmt：例 "%.1f時間"）。背景の映像も題材に合わせる（148 は机で作業する手元）

## 冒頭5秒で離脱させないための決まり（11/26 ユーザー指定・149 から）
- 冒頭の流れるランキングは項目名を「？？？」で隠す（hide_names）
- 帯の中に問いかけ（例「あなたの職業は／何位？」）。大きく読めるよう2行で短く
- 帯は1フレーム目から出ている（danger_static・横から入ってこない）
- 動画の最初にチリン（chirin）
- 帯の場面は2秒（右はしに着くまで1秒＋止まって1秒）

新しく勝ち抜きシリーズを作るときは、short_143 をひな形にして、この決まりに全部したがう。部品は world_short.py の
`chain_cut`（棒グラフの場面）・`bars_draw`・`talks_draw`（テキストボックス）・`scroll_draw`（流れるランキング）・`vid_frame`（動画の背景）。

## 中身
- 数字は同じ基準でそろえる（例：上場企業・業種別の中央値）。基準がちがうものは最後に「※別格」として出す。出典は概要欄に書く
- 画面に順位は出さない。低い順に3つ比べる → 勝った1つが残って次の2つ（または1つ）と比べる → … と勝ち抜く
- 長さは 59.9 秒（項目の数と場面の長さで合わせる）

## 構成（ループする）
1. 冒頭：流れるランキングが右はし（いちばん高い項目）に着く → 1秒止まる・止まった瞬間に fanfare_pararappara
2. 「うちの業界 平均より上だよね…？」のような問いかけの場面（叫ぶマーモット高速版・大きな白い字）
3. 本編：対決ごとに「棒がのびる（2.5秒・drumroll）→ のび切ったらすぐ勝ち負け（explosion_chudoon）」
4. 最後：全項目の棒が左の低い項目から流れる（中身は左へ動く・各棒の上に猫）→ いちばん高い項目が画面に入る直前で終わる（冒頭へつながる）

## 見た目
- 上の帯：黄色い字・黒ふち。強調したい言葉だけ赤（例「業界別{r}平均年収／勝ち抜きバトル」）
- 背景：assets_video/wide の映像を縦に切り出してくり返す（143 は渋谷スクランブル交差点・少しぼかして暗く）
- 棒：比べるたびに上下の幅を使い切る（いちばん高い棒＝上いっぱい・いちばん低い棒＝55%）。ふつうは黄色、勝ちは赤。白い枠なし
- 下の白い札：項目名（青・勝ちは赤）＋金額（大きい字・のびるあいだ数え上がる）
- 猫：棒の下のほうに大きく（勝ち＝大・負け＝中）
- 勝った猫のセリフ：赤い太字のテキストボックス（白地・黒い太いふち）を勝った側の上のほうに。3行まで
- 負けた猫のセリフ：青い字の小さいテキストボックス（「上には上が…」「それはヤバイ」など悲しみ・ツッコミ）。字幕なしの猫がいてもよい
- 別格の項目：「※別格」を赤い字＋白い太いふちで大きく、帯のすぐ下に
- セリフは生々しく人間味のある本音（その業界の苦労・自虐・ツッコミ）。どの業界もけなさない
- 固定コメント案を必ず付ける
