# 猫ミーム素材の置き場所

長時間動画（横長 1920x1080）で使う猫ミームの素材をここに入れます。

## 置けるファイル
- 形式: `mp4` / `webm` / `gif` / `png`
- グリーンバック（緑の背景）の素材もOK。背景は動画を作るときに自動で抜きます
- 1ファイル **25MB まで**（GitHub のブラウザからのアップロード上限のため）

## ファイル名
中身が分かる名前にしてください。英数字と `_` がおすすめです。

- 例: `surprise_01.mp4`（驚く猫）、`dance_01.webm`（踊る猫）、`happy_cat_gb.mp4`（グリーンバック）
- グリーンバック素材は名前に `_gb` を付けてもらえると助かります（無くても判別します）

## アップロードのしかた（ブラウザ）
1. このフォルダを GitHub で開く
2. 右上の「Add file」→「Upload files」
3. ファイルをドラッグして入れる
4. 下の「Commit directly to the `claude/cat-meme-longform` branch」を選んで「Commit changes」

## 権利について
素材ごとに、配布元の利用条件（クレジット表記が必要か、YouTube で収益化してよいか）を確認してください。
分かる範囲で `CREDITS.md` に「ファイル名・配布元のURL・条件」をメモしてもらえると、概要欄のクレジット作成に使えます。
