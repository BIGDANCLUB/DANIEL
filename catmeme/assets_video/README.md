# 動画素材（動く背景）

ユーザーが用意した動画素材（10/13）。横動画用と縦（ショート）用に分けてある。**それぞれの向きに合ったものを使う**（ユーザー指定）。

- `wide/`（1920x1080・音なし）… 横の長尺動画用。カットの `bg` に名前を書くと動く背景になる（`cuts_04_leak.bg()` がここを先に探す）
- `tall/`（1080x1920・音なし）… ショート用。`short_refstyle.cut()` の背景に名前を書くと動く背景になる
- 素材が短いときは頭に戻ってくり返す。`bg_ss`（秒）で途中から始められる
- 元のファイルは別のブランチ（claude/fahrenheit-like-game-7MEBw）にアップロードされていたので、こちらに取り込んで名前を付け替えた
