## ニコニ・コモンズの曲を使うとき
- 作品ページ（https://commons.nicovideo.jp/works/nc番号）で **営利利用・YouTubeでの利用の条件** と **クレジットの書き方** を確認する
- 使った動画は、ニコニ・コモンズで **親作品登録（利用登録）** をする

## Cool_Not_Cool_60s.mp3（11/5 Sunoで自作）
- ショート用のシュールなファンキーハウス。元の曲の37.77秒〜97.77秒（2回目のドロップから最後のドロップの終わりまで）を60秒に切り、最後1.5秒をフェードアウト
- Cool_Not_Cool_60s.wav：配信用（TuneCore）。SunoのWAV（48kHz）から同じ場所を切って 44.1kHz・16bit・ちょうど60.000秒に変換

## Not_Sure_Not_Care_60s.mp3（11/6 Sunoで自作）
- Cool, Not Cool と同じコンセプトの女性ボイス版。元の曲（1:20）の19.83秒〜79.83秒を60秒に切った（最後の一発で自然に終わる）
- Not_Sure_Not_Care_60s.wav：配信用（TuneCore）。SunoのWAV（48kHz）から同じ場所を切って 44.1kHz・16bit・ちょうど60.000秒に変換
