# 「寸劇」シリーズの参考動画メモ

## 参考0（10/18・スマホ画面録画・21秒）冒頭
- 黒い画面に白い太字だけ →黒い画面の真ん中に写真＋下に字幕 → 寸劇。冒頭・導入は音なし、BGM は寸劇から
- 寸劇：役名は猫の頭の上（白い四角に黒い太字）。セリフは前のものを残して下に足す

## 参考1（10/19・PC画面録画・28秒）寸劇の本編（ゲームセンター）
- 背景は写真ふう（ゲームセンター）を全面。猫は左右に2匹、いつも両方いる。犬もあり
- **役名は画面の上の左右の角に固定**（「海外留学生」左上・「日本人JK」右上）。白い四角に黒い太字
- **セリフは話している側の猫の上に1行だけ**（左の猫は左寄り、右の猫は右寄り・画面の高さの7割あたり）。
  次のセリフで置きかわる（同じ側の前のセリフは消える。反対側のセリフは残ることもある）。白い太字＋細い黒縁
- **セリフごとに、話す猫の素材を表情に合わせて差しかえる**（笑う→驚く→真顔など）
- **強調カット**：話す猫に向かって画面ごとズーム（約1.5倍・役名も一緒に大きくなって上が切れる）。
  画面の下に大きな字幕：驚きは**黄色＋黒縁**、気持ちを込めたセリフは**赤＋白縁＋黄色の集中線**
- 音は最初から最後まで続く（BGM）

## 参考2（10/19・36秒）写真の語り → 夏祭りの寸劇
- **場面の切りかえに、黒い画面＋写真＋字幕の語り**をはさむ（話の途中でも使う）。写真は写真ふう（制服の2人がゲームセンター）
  例：「日本人にとっては、何でもない放課後。」→「しかし海外の10代には」→「アニメやSNSで見てきた／『日本の日常』そのものです。」
- **場面の始まりの強調カット**：話す猫にズーム＋**吹き出し（白い丸・黒い線）の中にイラスト**（浴衣の女の子）＋大きな**赤＋白縁**の字幕「浴衣だあああ！！」
- 同じ人のセリフが続くときは、**前の行を残して下に足す**（「髪飾りもネイルもかわいい！！」「りんご飴！！」「かき氷！！」）。区切りで消して次へ
- 強調カットの字幕の色：普通の驚きは**白＋黒縁**（「だって日本の夏祭りだよ！？」）、強い驚きは**黄色＋黒縁**（「それ学校なの！？」）、叫びは**赤＋白縁**
- 右の役（日本人JK）もセリフごとに猫・犬の素材を差しかえる（真顔の猫→犬→泣き顔の猫など）
- 背景はアニメふうの夏祭り（屋台・ちょうちん）。参考1のゲームセンターは写真ふう。**背景は場面ごとに1枚**

## 参考（5-4・10/19・35秒）3人の場面 → 黒画面の語り → 教室の場面
- **3人いる場面**：役名を上に3つ（左・真ん中・右）。猫も3匹並べる。セリフは話す猫の近く
- **時間を飛ばす語り**は、写真なしの**黒い画面に白い文字だけ**（「そんな何気ない日々を過ごし」→「交換留学の終わりが近づいた頃——」）
- 場面ごとに出る役だけ並べる（教室は「海外留学生」と「シャイボーイ」の2人。あとから「日本人JK」が入ってくると役名が増える）
- 役名は**その猫の頭の上あたり・画面の上の方**（左の役は左上、右の役は右寄り）
- 気持ちが動くところは、**話す猫の顔のアップ（画面いっぱい）＋真ん中に黄色の字幕を1行ずつ足す**（「な、なにこれ…」「この胸の高鳴り…」）
- 驚きのアップは **赤＋白縁** の字幕を下に（「クレーンゲームで取ったの！？」）
- 間（ま）は「……」で表す（「……うん」「……ありがとう」）。しんみりした場面でも猫ミームのまま

## 参考（5-6・10/19・29秒）締めの語り → 最後の場面 → 締め
- **締めの語り**：黒い画面＋写真（制服の2人）＋字幕「放課後に友達と寄り道して、一緒に笑って帰る。」→「日本人には何でもない日常が」→「海外から来た10代にとっては」→「アニメ以上に忘れられない／『アオハル』になるのかもしれません。」（BGM は続く）
- 最後の場面は**かわいいイラストの背景**（虹と草原）。3人並んで会話（「じゃあ最後に3人でプリ撮る？」「……」「撮りたい」「もう、好きじゃん」「何気ない日々、大切にしたいよね」）
- **締め**：3人とも**同じ踊る猫**に変わり、下に大きな白い字幕「チャンネル登録、お願いしまーす」（参考はオレンジの猫が赤い服で踊る素材）
- 音：写真の語りは BGM あり、黒い画面だけの語りは音なし

## まとめ（story_style.py で再現したもの）
- intro（黒＋白い文字・音なし）／photo（黒＋写真＋字幕・BGM 続く）
- Scene：役名は画面上に固定（左上・真ん中上・右上）、say（話す猫の差しかえ・add で下に足す・相手の直前のセリフは1つ残る）
- zoom：画面ごと寄る＋下に大きな字幕（white/yellow/red）、rays（集中線）、bubble（吹き出しイラスト）、pos="mid"（顔のアップ＋真ん中に黄色を1行ずつ）
- ending：全員同じ踊る猫＋「チャンネル登録、お願いしまーす」
