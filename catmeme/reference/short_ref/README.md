## 共通の作り（short_refstyle.py でマネ）
- 背景イラストを縦いっぱいに敷く。図やパネルは出さず、セリフだけで進める
- 上に黒い帯、2行タイトル（1行目は赤い大きな文字、2行目は黄色か白＋赤）。帯の上に背景が少し見える
- 猫ミームは画面の下半分に大きく1〜2匹（下の辺から生やす）。元の音を鳴らす
- セリフは帯のすぐ下、白または黄緑の太い文字＋黒い太縁。強調語だけ赤
- 擬人化した相手役（「相続税」「ママ」）は足元に黄緑の大きな文字、または白い四角に黒い文字で役名
- 1セリフ1.5〜3秒でテンポよく切り替え。オチは「でも安心してください〜」→どんでん返し
