# 制作指示書：ハッカー集団の中心メンバーが日本で捕まった → 直後にソフトバンク子会社のクラウドが乗っ取られた（2026年10月）

別セッション（猫ミーム時事ネタ分析）の調査まとめ。**9本目**。原稿は 03〜06 と同じ形式・ルールで `scripts/09_hackers.md` に起こす。

## なぜこのネタか
- TBS NEWS DIG「【独自】“日本は世界最悪のコンピュータセキュリティ体制” ハッカー集団『Qilin』中心メンバー拘束で取材に応じる」**52.9万回**（10/8時点）
- 10/7 未明、ソフトバンク子会社 IDCフロンティアのクラウドがランサムウェアで止まり、**画面にハッカーの犯行声明とみられるメッセージ**（NHK）。**495の企業・自治体**に影響
- **4本目「個人情報、盗まれすぎ問題」の続編**（4本目の「なぜ今連発？」の答え合わせ回）。7本目（ビール）とも縁：Qilin は2025年にアサヒを攻撃したと主張

## 注意（必ず守る）
- **Qilin と IDCF の攻撃が同じ犯人とは分かっていない**（どの報道も結びつけていない）。2つは「同じ週に起きた別々の事件」として並べ、「関係があるのでは？」はネットの声（憶測）として扱う
- 「日本は世界最悪のセキュリティ」は**攻撃者側の主張**。事実として言わない（「ハッカーがそう言った」と字幕で明示）
- 拘束された男は**名前が公表されていない**。Qilin は「同僚か肯定も否定もしない」
- SNSで広まった犯行声明の画像の文面（「YOUR CLOUD IS OURS」など）は**未確認**。IDCF は「声明の存在は把握、真偽を含め調査中」。使うなら「SNSで広まった画像によると」と明示し、画像そのものは使わず〔カード〕で要旨を再現
- まとめサイトの「7分で侵入」「7時間気づかず」「メッセージを225か所」は**一次情報で確認できない → 使わない**
- 攻撃の手口を「やり方」として説明しない（侵入方法の具体的な手順は出さない）
- 被害を受けた会社・自治体をバカにしない。笑いの対象はハッカーの“上から目線”と、ニュース猫の慌てっぷり

## 確認した事実

### A. Qilin の中心メンバーが日本で拘束 → ドイツへ
| 項目 | 内容 | 出典 |
|---|---|---|
| 誰 | ランサムウェア集団「Qilin（キリン）」の**中心メンバー**とみられる**ロシア国籍の男（28歳と報道）**。名前は非公表 | 時事・nippon.com・検索まとめ |
| どこで | **大阪市内**で日本の捜査当局が身柄を拘束（5月末に大阪へ移動中に拘束との報道も＝要確認） | TBS・報道 |
| 引き渡し | 恐喝容疑で捜査しているドイツ側の請求で、**10月2日**にドイツへ引き渡し。日独に**犯罪人引渡条約はない**が、逃亡犯罪人引渡法で相互主義など要件を満たせば応じられる。東京高裁が要件を満たすと判断 | 朝日（TBS記事内）・報道 |
| ドイツの容疑 | 2024年9月、ドイツの物流会社に侵入してデータを暗号化し、約16万5千ドル相当のビットコインを要求した疑い | 報道 |
| Qilin とは | **RaaS（ランサムウェアの貸し出し）**型。運営がツールや仕組みを用意し、実際の侵入は加盟者が行う。男は運営の中核で、身代金の取り分を得ていたとされる | 報道 |
| 日本との関係 | 2025年にアサヒグループへの攻撃を名乗った（ビール製造などに影響）。**拘束された男がアサヒの件に関わったかは不明** | nippon.com |
| 取材への回答 | Qilin は JNN の取材に声明で回答。メンバーについて「同僚であるか肯定も否定もしない」、捜査当局を批判。日本は「**世界最悪のコンピュータセキュリティ体制を持つ国のひとつ**」で、日本の企業・政府機関への攻撃は**今後増える可能性**がある、ただし「脅しではなく専門家としての見解」と強調 | TBS NEWS DIG |

## 構成案（約7〜9分）

### 1. つかみ
- 【字幕】10月2日　ハッカー集団の“中心メンバー”が　日本で捕まり　ドイツへ
- 【字幕】そのハッカー集団が　取材に答えた
- 【字幕】「日本は　世界最悪のコンピュータセキュリティ体制」
- ニュース猫「捕まった側が上から目線なの何!?」［angry 系］
- 【字幕】そして5日後　ソフトバンク子会社のクラウドが　乗っ取られた
- ニュース猫「フラグ回収はやすぎ」

### 2. 捕まったハッカー（A の表を〔カード〕で）
- 「Qilin」＝読みは“キリン”。ビールの会社じゃない（7本目への小ネタ。ただし Qilin がアサヒを攻撃したと主張していたのは事実として紹介）
- RaaS ＝「ランサムウェアの貸し出し」。運営が道具を貸し、実行役が攻撃、身代金を山分け → 4本目の説明を短く再利用
- 日本とドイツは引き渡しの条約がないのに引き渡した → 博識な猫「条約なしでも、条件がそろえば引き渡せる」

### 3. ハッカーの“声明”
- 要旨を字幕で：「同僚かどうかは言わない」「捜査当局は有罪が証明されていない人の人生を壊そうとしている」「日本は世界最悪のセキュリティ」「攻撃は増える。脅しじゃなく専門家の見解」
- ニュース猫「専門家ヅラすな」／博識な猫「でも“攻撃が増える”は、4本目で見た数字（ランサムウェア被害が過去最多）と合っちゃうのが悔しい」

### 4. そして起きた IDCF クラウドの攻撃（B の時系列）
- 「クラウド」＝会社や役所がホームページやシステムを置いている“借りてるサーバー”。1か所やられると**495か所がいっせいに止まる**
- 画面に出た犯行声明（NHK）／SNSの画像の主張（未確認）
- 「データが戻らないので別の所で作り直し」の会社も
- ニュース猫「県のホームページが見られないって、相当だよ」

### 5. 同じ犯人なの？（事実と憶測を分ける）
- 事実：**関係は分かっていない**。IDCF は声明の真偽も含めて調査中
- ネットの憶測（**確認されていない**）：「仲間を捕まえた報復では」「声明どおり攻撃が増えた」「たまたま同じ週」
- 博識な猫「“タイミングが近い”は“同じ犯人”の証拠にはならない」

### 6. 私たちにできること（4本目の対策を短く再掲＋会社向けを一言）
- 個人：お知らせ・お詫びメールのリンクは踏まない／パスワードの使い回しをやめる／二段階認証
- 会社・自治体：バックアップを“別の場所”に（今回、別の場所にバックアップがあった会社は移行できている）

### 7. ネットの声（架空の要約。実際の投稿をそのまま引用しない）
- 「ハッカーに“世界最悪”って言われるの、通知表より効く」
- 「捕まえた直後にこれ、完全に挑発」
- 「“YOUR CLOUD IS OURS”ってセリフ、映画でしか見たことない」
- 「県のHPが見られないの、地味に怖い」
- 「Qilin（キリン）とビールの話がつながるの、偶然にしてはできすぎ」
- 「悔しいけど“世界最悪”に言い返せない」
- 「バックアップ取ってた会社が勝ち組」

### 8. まとめ
- 〔カード〕分かっていること／分かっていないこと（同じ犯人か・どこから入られたか・情報は漏れたか）
- 締め：4本目・7本目への誘導
