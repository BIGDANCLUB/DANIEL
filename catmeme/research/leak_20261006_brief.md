### 2. なぜ起きているか（手口）
9月に原因まで公表された10件の侵入の起点（udon-dev のまとめ）:
- **外から触れる入口の穴**が6件：VPN機器（デジタル庁）、Webシステム（ムラウチ）、画像アップロード（Gyazo）、管理画面のログイン（スマレジEC）、アップロード機能＋設定不備（PhotoGoods）など
- 設定の不備：CMS の設定から API の鍵を狙われた（集英社）
- フィッシング → メールアカウント乗っ取り（東洋紡グループ）
- **攻撃者がいない漏えい**：TOPPAN が損保ジャパン契約者 17万7,426名分を**ドラッグ&ドロップの誤りで同業他社へ誤送付**／RIZAP が約2万人分を**外部の生成AIに入力**／愛知県のサイトで**8年間**誤掲載／りそな銀行は紙の紛失
- 例え案：VPN＝「社員用の通用口」、脆弱性＝「壊れた裏口の鍵」、ランサムウェア＝「データを人質に身代金」

### 3. なぜ今、連発しているのか（事実 → 憶測の順。憶測は必ず「〜という声も」と明示）
事実・統計
- ランサムウェア被害は 2026年上半期 123件で半期として過去最多（2022〜2025年の上半期は 114・103・114・116件）（警察庁）
- ランサムウェアの侵入経路の**約5割が VPN 機器**（警察庁）
- 「RaaS（ランサムウェアの貸し出し）」で、技術がなくても攻撃できるようになった
- IPA の「10大脅威」に**AIの利用をめぐるリスク**が初めて入った
- **AIで自動化した攻撃**の実例：9/10〜15 の5日間、人間が指揮して AI エージェントがほぼ自律的に100超の組織を攻撃、30以上のサイトに侵入、カード番号60万件超を窃取（Gambit Security の報告／Forbes JAPAN）。**費用は約8,000ドル**。※日本の今回の件と同じ犯人という根拠はない
- 一方で「件数そのものが急増したとは言い切れない」という見方も：上場企業の漏えい事故件数は2025年に**減っている**が、**100万人超の大型が2件→6件**に増えた（東京商工リサーチ）。「漏えいの**おそれ**」の段階でも報告が義務になった（個人情報保護法の改正）ので、発表が増えて見える面もある
ネットの憶測（掲示板の傾向。どれも根拠は確認されていない）
- 「AIで誰でも大量に攻撃できるようになったから」（いちばん多い）
- 「日本企業はセキュリティにお金をかけない」「古いシステムと IT に弱い経営陣」
- 「中の人（社員・委託先）が流している」
- 「同じ犯人・同じ穴では？」「国が絡んでいる」
- 「もう全員の情報は漏れ済み。今さら」（諦め）

### 4. 個人情報を盗まれると何が起こるか
- 今のところ多くの会社が「悪用（二次被害）は確認されていない」と発表 → 字幕で正確に
- 心配なのはこの先：
  - **名前＋電話＋メール**がそろう → 本物っぽい偽 SMS・偽メール（「お荷物の不在通知」「お詫びのクーポン」「返金のご案内」）
  - **送り主・届け先**がわかる → 「最近荷物を頼んだ」ことを知った上での詐欺
  - **免許証の画像** → なりすまし（口座開設・契約）に使われるおそれ
  - パスワード使い回し → 別のサービスに次々ログインされる
- ABAHOUSE の「本物の注文と一致する返金メール」が確認できれば実例として使う

### 5. 対策はないのか
1. 「漏えいのお知らせ」「お詫び」メールのリンクは踏まない。**公式アプリ・ブックマークから**確認
2. 使い回しのパスワードを変える（漏れた所と同じものを他で使っていないか）
3. 二段階認証・パスキーを入れる
4. 荷物の SMS・お詫びクーポンは、まず疑う
5. 使っていないアカウントは退会（持っているだけで漏れる）
6. 免許証などの画像を出したサービスは、身に覚えのない契約・郵便に注意
- 締めの一言案：「“漏れない”じゃなくて、“漏れても被害にならない”ように守るのが今のやり方」
