# 東大の新しい総長、投票2位の人が選ばれた件（原稿 v3：猫ミーム再現・字幕のみ）

- 想定尺: 約7分（約110カット・1カット3〜5秒）
- 形式: **声は入れない。すべて字幕。** 出来事の説明はナレーション字幕、登場人物は猫ミームが演じ、セリフは吹き出し字幕で出す。音は猫ミーム素材の音（著作権のある曲は消す）＋BGM＋SE
- 書き方:
  - `【字幕】` … 画面下などに出す出来事の説明
  - `猫（役）「セリフ」` … その役の猫ミームを映し、セリフを吹き出し字幕で出す
  - `［素材］` … 使いたい猫ミームの種類（素材が届いたらファイル名を割り当てる）

## 表示ルール
- 冒頭に【字幕】「※実在の人物の言葉は、報道をもとにした要旨です」「※猫は再現のための演出です」
- 実在の人（藤垣さん・議長）のセリフは、報道された内容から意味を変えずに口語にしたもの。報道にない発言は作らない
- 架空の猫（ニュース猫・先生たち・会議の猫たち・ネットの猫たち）は思いきりくだけた口調でOK。ただし実在の人をバカにする言い方はしない
- 冒頭か概要欄に、AIで生成した部分（画像など）があればその旨を表示
