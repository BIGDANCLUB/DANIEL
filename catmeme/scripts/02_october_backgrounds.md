# 背景イラスト発注メモ：02_october_changes（10月1日から変わったこと）

猫ミーム（グリーンバックを抜いた猫）を上にのせるための背景イラスト。

## 共通の仕様（01と同じ）
- サイズ: **1920x1080 の PNG**（横長）
- 置き場所: `catmeme/backgrounds/02_october/`、ファイル名は下の表の `bg12_liquor_shelf.png` など
- 絵柄: **01の背景とそろえる**。やわらかい手描き風のアニメ背景（明るめ・彩度ひかえめ）。**人物・動物は描かない**（猫は後からのせる）
- **画像の中に文字を入れない**（値札・商品ラベル・看板・ロゴ・ポスターの文字もなし。缶や箱は無地か、色と模様だけ）
- 実在のお店・会社・商品に似せない（コンビニやスーパーのロゴ・制服の色・特定の缶デザインはNG）
- 構図: **画面の中央下あたりを空ける**（猫を立たせる場所）。**下から1/4は字幕が乗る**ので、細かい描き込みを避ける
- AIで作った場合は、そのことを記録しておく（動画の概要欄に「AI生成」と表示するため）
