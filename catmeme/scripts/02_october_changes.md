- 書き方:
  - `【字幕】` … 出来事の説明（ナレーション）
  - `猫（役）「セリフ」` … その役の猫を映し、セリフを大きい文字で出す
  - `［素材］` … 使う猫ミーム（`assets/` のファイル名。仮。カット割りで調整）
  - `〔カード〕` … こちらで作る解説カード（表・棒グラフなど）
- 実在の人物は出てこない。税額などの数字は公式の情報で確認してから確定する

## 確認メモ（台本確定前に一次情報で再確認すること）
- 酒税額（350ml）: ビール 77→70→63.35→54.25円、第三のビール 28→37.8→46.99→54.25円、発泡酒（麦芽25%未満）46.99→54.25円、チューハイ等 28→35円 … 国税庁の資料で確認
- 「2018年に決めた」… 改正法の成立は2017年（平成29年度税制改正）、施行の起点が2018年。言い方を確認
- 加熱式たばこの値上げ幅（1箱20〜40円）と、紙巻きの増税開始（2027年4月）… 財務省・JT等の発表で確認
- 帝国データバンク: 10月 3,033品目（8月31日時点）、2026年1〜11月 1万9,083品目 … 最新の発表で数字が変わっていないか
- ゆうパック平均約10％、クリックポスト240円、ゆうパケット一律360円 … 日本郵便の発表で確認
- 106万円の壁: 10月1日撤廃、週20時間以上が基準、企業規模要件（51人以上）は2027年10月から段階的に縮小 … 厚生労働省のページで確認
