# 背景イラスト発注メモ：03_kodomo_nisa（こどもNISA）

猫ミーム（グリーンバックを抜いた猫）を上にのせるための背景イラスト。

## 共通の仕様（01・02と同じ）
- サイズ: **1920x1080 の PNG**（横長）
- 置き場所: `catmeme/backgrounds/03_kodomo_nisa/`、ファイル名は下の表の `bg19_kids_room.png` など
- 絵柄: **01・02の背景とそろえる**。やわらかい手描き風のアニメ背景（明るめ・彩度ひかえめ）。**人物・動物は描かない**（猫は後からのせる）
- **画像の中に文字を入れない**（看板・ロゴ・ポスター・本の背表紙・画面の文字もなし）
- 実在の銀行・証券会社・学校に似せない（ロゴ・制服・建物そっくりはNG）
- 構図: **画面の中央下あたりを空ける**（猫を立たせる場所）。**下から1/4は字幕が乗る**ので、細かい描き込みを避ける
- AIで作った場合は、そのことを記録しておく（動画の概要欄に「AI生成」と表示するため）
