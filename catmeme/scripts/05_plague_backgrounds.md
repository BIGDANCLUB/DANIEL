# 背景イラスト発注メモ：05_plague（ロシアのペスト研究所）

## 共通の仕様（01〜04と同じ）
- サイズ: **1920x1080 の PNG**（横長）
- 置き場所: `catmeme/backgrounds/05_plague/`、ファイル名は下の表のとおり
- 絵柄: **01〜04の背景とそろえる**。やわらかい手描き風のアニメ背景。**人物・動物は描かない**（猫は後からのせる）
- **画像の中に文字を入れない**（看板・ロゴ・ラベル・国旗もなし）
- **こわすぎない**：病人・遺体・血・ドクロ・死体の山など、亡くなった方を連想させる描写はNG
- 構図: **画面の中央下あたりを空ける**。**下から1/4は字幕が乗る**ので細かい描き込みを避ける
