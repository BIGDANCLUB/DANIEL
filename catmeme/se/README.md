# 汎用SE置き場（猫ミーム長尺動画）

ここに効果音（mp3 / wav / m4a）を入れる。どの動画でも使い回してよい。

- ファイル名は中身が分かる英数字がおすすめ（例: `don.mp3`、`pon.mp3`、`drumroll.mp3`、`kirakira.mp3`）
  - 日本語のファイル名でも使える
- ここに `don` / `pop` / `drum` / `chime` と同じ名前のファイルを置くと、合成の効果音の代わりにそれが使われる
- 配布元が分かるよう、下の表に1行書き足す（概要欄のクレジット用）
