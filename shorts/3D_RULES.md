# 3D「もしも」シリーズのルール（ユーザー指定）

- ベンチマーク：@basuragnews（バスラッグ、ニュース）のショート。作り方・構成はできるだけ精緻に真似し、題材と登場人物だけ変える。
- 投稿先チャンネル名：「もしもジャパン」（ユーザー指定）。ベンチマークは @basuragnews と @yoneapp-games の2つ。
- ナレーションなし。効果音と BGM のみ。透かし @nihon_de_ikiru は一旦外している（E-003 から）。
- リプレイ（巻き戻し）は使わず、だんだん大きくなっていく一本の流れにする（電車 E-002 から）。
- **物理現象の変化を必ず出す（全動画に適用）**：数が増える・速くなる・重くなることで起きる現象を、段階ごとに目で見せる。
  - 例：重くなる → 車輪の火花、レールのきしみ、地面のひび割れ・沈み込み
  - 例：大きな物が動く → 押しのけた空気の衝撃波、ビルの窓ガラスが割れて飛ぶ、砂ぼこりの壁、雲の輪
  - 主役（電車など）は「壊れない設定です」と注記して、まわりだけが変化する
  - 字幕で数字（重さ・速さなど）と、起きた現象を一言で書く
- 長尺シリーズ「早送り系」：@はやおくり日本 をベンチマーク（土地の歴史を3Dで早送り）。
- ベンチマーク追加：@yoneapp-games（よねあぷゲーム実験室）。「もしも〇〇が消えたら？」系の3Dショート。
  - 人気：蚊 370万／日本 249万／カメムシ 236万／二酸化炭素 156万／渋谷（人がいなくなったら）104万／動物 99万。題材は「身近な物・生き物・地域が消えたら」と「〇〇が毎秒2倍」。
  - 見た目：ローポリ・角ばったブロック体の人（顔は簡単な目・眉）、明るい昼の色、Blender風の素直なライティング。
  - 画面の型：上にタイトル「もしも【キーワード色】が消えたら？」→ 左上「〇〇が消えてから ▶▶×倍速」＋大きな経過時間（例「21日 00:02」、色つき下線）→ 場所「📍日本・北海道 オホーツク海のホタテ漁」→ 中央下に大きな白い見出し（例「ホタテがやせていく」）＋小さな説明2行（数字入り）。
  - 構成：消えてから時間を早送りし、場所を変えながら連鎖する影響を次々に見せる。
- キャラの顔は今のまま（E-003 の目・眉・鼻つきの丸い頭）で固定。よねあぷ風のブロック顔には寄せない。
- よねあぷ「もしも蚊がいなくなったら？」（ユーザー提供の画面収録・約28秒）の構成：
  1. 冒頭（約0〜6秒）：消える前の場面。大きな2行タイトル（キーワードだけ緑）＋状況の一文「8月の夜。プーンという音で、また目がさめた」＋左「蚊が消えるまで 6.30秒」のカウントダウン。最初の1カットは世界の驚く事実（北極でトナカイが蚊から逃げまわる）でつかむ。
  2. 消える瞬間：白い光の粒になって消える。見出し「世界中の蚊が、消えた」＋説明「世界の蚊は3,700種以上 ぜんぶ消えた」。ここからタイトルは上に小さく1行、左上が「蚊が消えてから ▶▶×1」＋経過時間（00:02.29）に切り替わる。
  3. 最初は等倍で、すぐ近くの変化（プーンが聞こえない）→ ×1.2 → ×1,121 と早送りが上がる。
  4. 章カード：暗い画面に大きな白文字「次の夜」「1週間後」で時間を飛ばす。
  5. 場所表示「日本・夏祭り（夜7時）」→ 身近な良いこと（浴衣でも、かゆくない）。
  6. 地球儀で世界規模の影響（赤い地域＋「●マラリア」ラベル、「1年に約60万人が亡くなっていた」）。
  - 見出しは白の太字、説明は小さい白2行。下線つきの経過時間。音は途切れない（無音区間なし）。
- 同じ蚊の動画の続き（ユーザー提供の画面収録2本目・約34秒）：
  - 章ごとに約5〜6秒。章カード（「2か月後」「半年後」）は場面の上に大きな白文字で重ね、すぐ消える。経過時間は章の頭（30日 00:00、60日 00:00…）から数秒カウント。倍速表示は×71、×67など章ごとに変える。
  - 場所は世界中を回る：アフリカ・ナイジェリアの村（夜）→ ガーナのカカオ畑 → ガーナ・アクラ（野口英世記念医学研究所）→ アメリカ・ハワイの森 → カナダ・北極に近い湿地。
  - 見出しの種類を混ぜる：①良い変化（今夜から蚊帳はいらない）②うわさの否定（チョコは、なくならない：受粉はヌカカ）③歴史・人物（野口英世が命をかけた病気も消えた）④生き物の回復（消えかけた鳥がまた増えはじめる）⑤最後に「でも」で逆転（でも、ヒナのごはんがひとつ減った）。
  - 小物の演出：花が画面に浮かぶ、音符マーク、人物の銅像と名札など、説明を絵で補う。
- 蚊の動画の終わり（3本目の画面収録・約24秒、ここまでで1作品＝約1分20秒）：
  - 「1年後」→ 日本・おばあちゃんの家（8月）：子どもが押し入れから蚊遣り豚を見つけて「これ、なあに？」→「夏のにおいがひとつ消えた（蚊取り線香は1890年〜）」＝懐かしさで締める（50代男性に効く型）。
  - 「同じころ」ナイジェリアの村：女の子が「5歳の誕生日をむかえた（アフリカでマラリアで亡くなる人の多くは5歳未満）」＝感動の着地。
  - 最後は暗くした画面に「次は何が消えたら見たい？ コメントで教えてね（リクエストありがとう！）」。
  - 1年をすぎると経過時間は「1年 0日 00時」の表記に変わる。
- よねあぷ「もしも動物が消えたら？」（99万回・画面収録5本、約2分）の構成：
  1. 冒頭：日曜午後3時の公園、子どもと柴犬。「あと4秒でこの子は消える」＝感情移入できる1匹を最初に見せる。
  2. 同じ瞬間：子ども部屋のハムスター、セレンゲティ →「地球に残った動物は人間だけ（推定777万種のうち、たった1種）」。
  3. 10秒後〜数日：身近で小さな変化を連打（音がしない／日本中で名前を呼ぶ声／ハーネスが軽くなった（盲導犬768頭）／知らない人がひじを貸した／ゴキブリも蚊もいない／顔のダニも消えた）。
  4. 1週間後：地球儀＋右に小さな絵パネル（場所名つき）で世界の影響を約10秒ずつ（蚊の病気／海から魚／サンゴも動物だった／牧場がからっぽ／卵で作るワクチン／8割以上は名前もないまま消えた）。
  5. 1か月後〜：日本の店で生活の変化（スーパーのたんぱく質が半分以上消える／ラーメンが作れない→昆布は消えなかった）。安心（人類は滅びない／大豆プロテイン／桜は来年も咲く）と逆転（花は咲くが実がならない／森を植えていたのは動物だった）を交互に。
  6. 10年後〜50年後：草原が燃える、色のある花が減る。60年後：孫が写真を見て「これなあに？」。
  7. 山場：冒頭の公園で同じ人が毎年同じ日にボールを投げる（6年→12年→…→58年、子→大人→老人）「こんどは人が待つ番だった（ハチ公は約10年）」。
  8. 59年364日23時で倍速を×1に戻し、60年後の同じ日・同じ時刻に光の粒から柴犬が戻る →「世界中の動物がもどってきた！ 動物たちにとっては1秒もたっていない」→ 老人が抱きしめ「おかえり 60年待っていた」→「次は何が消えたら見たい？」。
  - 最強の型：冒頭で1匹に感情移入 → 長い早送り → 最後に倍速×1で同じ場所・同じ時刻に再会（伏線回収）。
- 動画の長さ：59.9秒固定はなし。参考元（よねあぷ）と同じくらいの時間割でよい（ユーザー指定）。

## 概要欄の型（もしもジャパン・ユーザー確定版／C-002）
タイトル例：「もしも日本からカラスが消えたら？ 〜10年後〜」
```
もしも、ある朝とつぜん日本から〇〇が消えたら？
いなくなって初めてわかる、その役割とは。

あなたなら、何が消えたら困る？
「次はこれが消えたら見たい」もコメントで教えてください。

※統計や研究をもとにした「もしも」の話です。実際の出来事ではありません。
※（数字の出典を1行で）

#もしもジャパン #もしもシリーズ #〇〇 #もしも #雑学 #3Dアニメ #shorts
```
- 短く。経過時間ごとの箇条書き（ネタバレ）は入れない。
- 2行目は題材に合わせて言い換えてよい。
