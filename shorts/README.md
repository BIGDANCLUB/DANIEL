# ショート動画ジェネレーター

縦型ショート（1080x1920・45〜55秒）を台本JSONから作ります。
全面画像を1行ごとに切り替え、画面中央に縁取り字幕（`{黄}` `<赤>`）を出す形式です。BGMは入れません。

## 準備
- 環境変数 `GEMINI_API_KEY` に Gemini API キーを登録（音声・画像の自動生成に使用）
- `pip install -r shorts/requirements.txt`

## 流れ
1. 台本 `story_xxx.json` を書く（`story_st003b_ai.json` が見本）
   - `text` … 字幕。`\n` で改行、`{…}` 黄、`<…>` 赤。`"hook": true` で大きい黄色のフック
   - `say` … 読み上げ文（省略時は `text` から自動）。読み間違いの修正にも使う
   - フィクションなので具体的な人名は出さない（「私は〇〇、72歳です」のような名乗りは入れない。年齢や立場は「72歳の私」「定年して」などで伝える）
   - 声（`tts.voice`）は語り手（登場人物）の性別に合わせる（視聴ターゲットの性別ではない）。男性語りの見本は `story_st004_ai.json`（Algenib）
   - `tone` … その一文の気持ち（例「不安で声が沈む。ゆっくり」）。`tts.style` の人物像・演技指示と合わせて TTS に渡し、抑揚をつける
   - `prompt` … その行の画像の指示（英語推奨・画像内に文字を入れない）
   - 画像は場面で指定してもよい: 台本トップの `scenes` に `{"名前": {"prompt": "..."}}`、行に `scene`（と任意で `crop` `[中心x, 中心y, 拡大率]`）。1つの場面は続く2〜3行まで（作品をまたいだ使い回しは禁止）
   - `move` … `in` / `out` / `left` / `right` / `up` / `down`（省略時は自動で交互）
   - `se` … その行の頭に効果音（`coin` チャリン などの合成音、または `se/` に置いたファイル名）
   - 冒頭SE … 全動画の0秒目に `se/チリン.mp3` を固定で鳴らす（1行目の `se` より優先）。台本トップの `intro_se` で別のファイル名、`"none"` で無し。`intro_se_volume` で音量（dB、既定 -3）
   - 台本トップの `banner` … 画面上部に出し続ける概要帯（`\n` で2行、`{…}` 黄）
   - BGM … `bgm/` に置いた曲から動画ごとにランダムで1曲選び、全編に流す（冒頭0.8秒フェードイン、最後2秒フェードアウト、声の間は自動で音量を下げる）
     - 台本トップの `bgm` … 省略で全曲からランダム、`"random:スカッと"` で `bgm/スカッと/` の中から、`"曲名.mp3"` で指定、`"none"` でなし
     - `bgm_volume` … BGMの音量（dB、既定 -10。声より約10dB小さくなる。大きい/小さいときはここで調整）
     - 選ばれた曲は `out/xxx_work/bgm_choice.txt` に記録され、作り直しても同じ曲になる（変えたいときはこのファイルを消す）
   - 赤字 `<…>` は表示直後にもう一度ポンと弾む
2. `python3 make_short.py story_xxx.json out/xxx.mp4`
   - 足りない音声（Gemini TTS）と画像（Gemini 画像モデル）を生成してから動画を書き出す
   - 生成物は `tts.voice_dir` / `image_gen.image_dir` に保存され、次回は再利用
3. 直したいとき
   - 画像だけ作り直す: `python3 gen_images_gemini.py story_xxx.json --only 3,7`
   - 声を全部作り直す: `python3 tts_gemini.py story_xxx.json --force`
   - 手で用意した音声・画像は `NN.wav` / `NN.png` として同じフォルダに置けばそれを使う
   - 尺が45〜55秒から外れると、合わせるための `tempo` の目安を表示する
   - 感情をこめた読みは行の途中に長い間が入りやすい。台本トップの `max_pause`（秒、既定0.3）より長い間は自動で詰める

## 全動画のルール
- **作品をまたいだ画像の使い回し禁止**（YouTube に量産と判定されないため）。画像は作品ごとに新しく生成する（scenes の `library` 指定はエラー）
  - 1本の中では、続く2〜3行で同じ画像を切り出し（`crop`）を変えて使ってよい（1本あたり8枚前後に抑える）。離れた行での再登場はエラー
- **ループ型**（台本トップに `"loop": 1.0`）は「答えを明かす」タイプの動画だけで使う。最後の行の表示から1秒後で切り、その後ろを先頭に回す。ループ型はチリン無し
- それ以外（制度系・人物伝など）は、冒頭フック＋チリンのこれまでの作り方

## 画像ライブラリ（記録用）
- 生成した画像は記録として `library/` に JPEG で登録されるが、再利用はしない
- `python3 gen_images_gemini.py --library 病院` … キーワードで一覧（名前とプロンプト）
- `python3 gen_images_gemini.py story_xxx.json --seed-library` … 生成済みの画像をまとめて登録
- 画像モデルの既定は `gemini-3.1-flash-lite-image`（通常版と画像トークン数は同じで、画質もほぼ同等）

## サムネイル
- `python3 make_thumb.py story_xxx.json out/xxx_thumb.jpg` … 1080x1920 のサムネイル（API不要）
- 背景は1行目の画像、見出しは台本トップの `thumb`（`\n` で改行、`{黄}` `<赤>`）。タグは `thumb_tag`（省略時は banner の1行目）

## その他
- `python3 tts_gemini.py --list-models` … 使える TTS モデル名の確認（モデル名が変わったとき用）
- `story_st003b.json` … 元動画の声と背景を再利用する版（`--source 元動画.mp4` が必要。背景は `extract_plates.py` で作成）

## ドキュメンタリー風（参考動画と同じ作り）
- `python3 make_doc_short.py story_doc001.json out/DOC-001.mp4`（見本は `story_doc001.json`）
- 上部の帯なし。1文ごとに全面写真を動かす（カットごとに ズームイン→左へ→ズームアウト→上へ→右へ→下へ の順。台本の `"move"` で個別指定も可）、中央に短いフレーズ字幕（白・太い黒縁・影、`{黄}`＝#FFFF00 `<赤>`＝#FF0000、102px・黒縁11px＝参考動画の実測値）を次々に表示
- 字幕はできるだけ2行で1ページにまとめる（1行10文字まで）。「のである」「日本の宝は」だけのような、表示が一瞬で終わるページは作らない
- 字幕の切り替え: VOICEVOX のときは、VOICEVOX が返す音ごとの時刻から求める（読み上げとずれない）。Gemini の声のときは、読みの長さで見積もって実際の音声の間に合わせる
- 字幕は出るたびに、小さく現れて一瞬104%まで大きくなり、100%に戻る（参考動画を30fpsで実測した動き）
- 1行目の `subs` はフック文のブロック（1行8〜9文字までで改行すると縮まない）
- 声は `tts`（男性）。VOICEVOX（青山龍星など）に差し替えるときはここを置き換える
- ルール
  - 尺はぴったり 59.9 秒（10/20 ユーザー指定。以前は 60.00 秒）。原稿の量と、読み終わり後の空白で合わせる。入りきらないとエラーで止まり、削る秒数を表示
  - 参考動画の最後のエンディング（ご視聴ありがとうございます等）は使わない
  - 冒頭に `se/チリン.mp3`
  - こちらから渡す画像・動画は scenes に `{"file": "パス"}` で指定。1本で2回まで（超えるとエラー）。足りない分は Gemini で生成

### VOICEVOX（青山龍星）の声を使う
- **自動（おすすめ）**: 台本の `tts` を `{"engine": "voicevox", "speaker": "青山龍星", "style": "ノーマル", "speedScale": 1.1, "voice_dir": "work_docXXX/voice_vv"}` にするだけ
  - エンジンが動いていなければ `tools/voicevox_setup.sh` が自動でダウンロード（約1.8GB）・展開・起動する（コンテナが作り直された後も自動）
  - 話す速さは `speedScale`、抑揚は `intonationScale`。作った声は voice_dir に保存して使い回す
- **PCで書き出す場合**:
1. `voicevox/docXXX.txt`（台本の読み上げ文を1行ずつ並べたもの）を VOICEVOX で「ファイル → テキスト読み込み」
2. 全部の行のキャラクターを「青山龍星」にする（話速などはここで調整）
3. 「ファイル → 音声を全て書き出し」で、フォルダ `voicevox/docXXX/` に書き出す（001_…wav, 002_…wav … と行の順に並ぶ）
4. そのフォルダを送ってもらい、台本の `tts` を `{"engine": "voicevox_files", "dir": "voicevox/docXXX"}` にして書き出す
- 概要欄に「VOICEVOX:青山龍星」のクレジットを必ず入れる（VOICEVOX の利用規約）

### 背景に動画・渡された画像を使う
- scenes に `{"file": "../catmeme/assets_video/wide/v06_cash_counting.mp4"}` のように書く（動画は画面いっぱいに切り抜いて流す。`"ss": 秒` で途中から）
- 使える素材: `../catmeme/assets_video/`（wide 22本・tall 5本、一覧は同フォルダの README）、`../catmeme/backgrounds/`（背景画像）
- 渡された素材は1本で2回まで
