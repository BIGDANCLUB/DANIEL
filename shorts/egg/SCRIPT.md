# もしも人間がタマゴで生まれたら？（台本 v1・約52秒）

- 型：もしもジャパン（よねあぷ型レイアウト）。ナレーションなし、効果音＋BGM。フェロモン（PH-001）・ドキドキ（DK-001）と同じ世界。主役は、あの朝に出会って結婚した若い2人。
- 最初の5秒を激しく動かす：病院の新生児室の列をカメラが走る → 5.6秒で、赤ちゃんがいっせいに大きなタマゴに（ぽん）。
- 物理：大きさと重さ／37℃で温める・向きを変える（転卵）／丸い殻は上からの力に強い（アーチ）／ひなは卵歯で殻をわる。
- 恋愛の要素（ユーザー指定「ちょっとだけ恋愛・性的な要素」）：2人のタマゴ、お父さんもタマゴを温める、かえるまで2人で待つ。

## 事実メモ（出典）
- 新生児は約3kg。人の妊娠は約40週（約9か月）。
- カモノハシ（とハリモグラ）はタマゴを産む哺乳類（単孔類）。
- ダチョウの卵は約1.5kg（ニワトリの卵 約24個分）、長さ約16cm。殻の強さは約70kg（Turkish J. Vet. Anim. Sci. 2009）で、大人が乗ってもわれにくい。ニワトリの卵は3〜4kg。
- 人のタマゴの重さは「もしも」の計算：鳥のひなはタマゴの重さの約3分の2 → 3kg の赤ちゃんなら約4.5kg（ダチョウの卵の約3倍）。
- 鳥の卵は約37.5℃で温め、親は1日に何度も卵の向きを変える（転卵）。
- コウテイペンギン：オスが南極の冬に、足の上の皮のひだで卵を約2か月（64〜75日）温める。その間ほとんど何も食べない（WWF ほか）。
- 鳥のひなは、くちばしの先の「卵歯」で殻をわる。
