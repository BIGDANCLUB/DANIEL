# PK-001 立体駐車場：タイトルと概要欄（作り方シリーズ・レッサーパンダ）

## タイトル
立体駐車場の作り方

（別案）
- 駅前の立体駐車場の作り方
- タワーパーキングの作り方

## 概要欄
```
空き地に白い線を引けば、それはもう駐車場？
でも駅前の土地はせまくて、10台しか止められません。
鉄骨で床を重ね、坂道は17%まで。エレベーターで車ごと持ち上げて、床ごと回す――
レッサーパンダが、立体駐車場のしかけをひとつずつ作りながら解説します。

次に「作り方」を見たいものをコメントで教えてください。

※しくみをわかりやすくするための3Dアニメです。大きさや形、作る順番は実物とは異なります。
※坂の勾配（17%まで）は駐車場法施行令の技術的基準、人を見はるセンサーは国土交通省「機械式駐車設備の安全対策」などをもとにしています。車1台の重さは目安です。
VOICEVOX:青山龍星
```
- 主人公はレッサーパンダ（ユーザー指定）。最初と最後はドリルを使う場面（ユーザー指定）。
