# RF-001 いかだ：タイトルと概要欄（作り方シリーズ・レッサーパンダ）

## タイトル
いかだの作り方

（別案）
- 太平洋を渡れるいかだの作り方
- 101日航海できるいかだの作り方

## 概要欄
```
丸太を縄でしばれば、それはもういかだ？
でも重い丸太は沈み、大波でひっくり返り、縄はこすれて切れ、流されるまま――
バルサ、アウトリガー、木の棒、舵、帆、センターボード。
レッサーパンダが、いかだのしかけをひとつずつ作りながら解説します。
1947年、本当にバルサのいかだで太平洋を渡った6人の話も。

次に「作り方」を見たいものをコメントで教えてください。

※しくみをわかりやすくするための3Dアニメです。大きさや形、作る順番は実物とは異なります。
※コンティキ号（ヘイエルダールら6人、1947年）：ペルーからツアモツ諸島のラロイア環礁まで101日、約6,980km。
VOICEVOX:青山龍星
```
