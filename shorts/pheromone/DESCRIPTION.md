# PH-001 フェロモン：タイトルと概要欄

## タイトル
もしも男女がフェロモンを出すようになったら？ 〜1年後〜

（別案）
- もしも人間にフェロモンが出たら？ 〜52歳課長のモテ期〜
- もしも男女がフェロモンを出したら？ 〜街じゅうが迷子に〜

## 概要欄
```
もしも、ある朝とつぜん、男も女も「フェロモン」を出すようになったら？
人生初のモテ期は来るのか。においの流れ方と、本当にあった研究で考えます。

あなたなら、何が「出る」ようになったら困る？
「次はこの“もしも”が見たい」もコメントで教えてください。

※研究をもとにした「もしも」の話です。実際の出来事ではありません（1959年のカイコの話、1995年のTシャツ実験は実際の研究です）。
※人間の性フェロモンは、まだ見つかっていません（Wyatt 2015）。カイコガのフェロモンはブテナントら（1959年）、交信かく乱は青森県・岩手県の資料より

#もしもジャパン #もしもシリーズ #フェロモン #もしも #雑学 #3Dアニメ #shorts
```
- 短く。経過時間ごとの箇条書き（ネタバレ）は入れない（概要欄の型どおり）。
- フェロモンは目に見えないので、動画ではピンク色のけむりで見せている（字幕で注記）。
