# シリーズ設計メモ：むかしばなし × 科学（ショート）

## シリーズ名の案
1. **むかしばなしにマジレス**（推し。検索されやすく、1秒で中身が伝わる）
2. おじいさん、それ物理的に無理です
3. 理科で読み解くむかしばなし（真面目寄り。概要欄やプレイリスト名向き）

台本 JSON の `banner` は「むかしばなしにマジレス\n{各話のサブタイトル}」で統一している。

## 語り口
- **ナレーター**：囲炉裏端でむかしばなしを語る70代の語り部じいさん。ただし中身は筋金入りの理系オタク
  - 「むかしむかし…」はゆったり語るのに、数字が出た瞬間に早口になる。その落差で笑わせる
  - オチは真顔でぼそっと言う（ボケていることに本人は気づいていない）
  - 名乗らない（README の方針どおり、名前は出さない）
- **声**：`Algenib`（しゃがれ系の男声。st004/st007 で使っていて相性がわかっている）。もっと軽くしたいときは `Puck`、落ち着かせたいときは `Charon` を試す
- **`tts.style` 案**（3本とも同じものを入れてある）

```
# AUDIO PROFILE
70代の日本人男性の語り部。囲炉裏端で子どもにむかしばなしを聞かせる、少ししわがれた温かい声。ただし中身は筋金入りの理系オタク。
## THE SCENE
昔話を語っているつもりが、科学の話になると我慢できずに早口で熱くなってしまう。
### DIRECTOR'S NOTES
「むかしむかし」はゆったり昔話調。数字や科学用語が出たら急にテンポを上げ、得意げに強調する。オチの一文は真顔でぼそっと言う。棒読みにせず、間延びさせず、テンポよく。
```

行ごとの `tone` は「昔話調／理系スイッチ（早口）／真顔でぼそっと」の3種類を基本に、行ごとに切り替える。

## 毎回の型（15〜20行・約50秒）
| 区間 | 行 | 中身 |
|---|---|---|
| フック | 1 | 科学の結論をいきなり言う（「桃の重さ250キロ」）。数字か、ありえない言い切りにする |
| むかしばなし | 2 | 「むかしむかし…」で元の話を1行だけ思い出させる |
| ズレ① | 3〜8 | 科学を当てはめて話を壊す → 無理やりな解決（水路を掘る など） |
| 豆知識 | 1〜2行 | 本筋から外れた小ネタ（猫は甘味がわからない など）。「へぇ」を稼ぐ |
| ズレ② | 残り | 見せ場のシーン（鬼退治・小づち・月へ帰る）にもう一度科学をぶつける |
| オチ | 最後から2行目 | 科学の結果、昔話が台無しになる一文（沈む／停電／距離を置く） |
| 問いかけ | 最終行 | 「あなたなら？」で、コメントで答えやすい質問にする |

コツ
- 科学ネタは1本で3〜4個。1本の中で「重さ」「距離」など1つのテーマでつなぐと、オチまで話が通る
- 数字は字幕に出す。読み上げは `say` で「センチ」「キロ」「ピーエイチ」など、読み間違えない書き方にする
- 字幕は1行12字まで。強調は1行に1つ（`<赤>` はオチと衝撃の数字だけ）

## 画像の統一スタイル（`image_gen.style` 案）
写実寄りの既存シリーズと見分けがつくように、**昔話の絵本風（和紙に水彩＋墨線）**にする。現代の道具も同じタッチで描くので、それだけで絵がボケになる。

```
Vertical illustration in the style of a traditional Japanese folktale picture book: soft watercolor and sumi ink on textured washi paper, warm muted earthy colors, gentle brush outlines, simple rounded character designs, rural old Japan setting. Modern scientific objects, when they appear, are drawn in the same brush style, which makes the scene look absurd and funny. Expressive comedic faces are fine. No text, no letters, no numbers, no symbols, no logos, no watermark.
```

- 特定の現代アニメ・作家の名前は画風の指定に入れない
- 数字は画像には入れず、字幕だけに出す（画像モデルは文字や数字を崩しやすいため）
- 画像代を抑えたいときは、主人公が出るカットを `scenes` にまとめて使い回す

## 試作3本の補足（別フック・タイトル・科学ネタの根拠）

### #1 桃太郎（`story_momotaro.json`）
**別フック**
- 「桃太郎の正体は\n<でっかい種>」
- 「鬼ヶ島の財宝\n川に流すと<全部沈む>」
- 「桃太郎の桃\n{1000倍}重かった」

**タイトル**
- YouTube：「桃太郎の桃、重さ250キロ説【むかしばなしにマジレス】」／「桃太郎、物理で詰む」／「金銀財宝を川に流した結果」
- 概要欄の一文：「大きさ10倍なら重さは1000倍。桃太郎を物理で読むと、おばあさんも財宝も大変なことになります。」

**科学ネタの根拠**
| ネタ | 根拠 |
|---|---|
| 桃 直径8cm・約250g | 大玉の桃の標準的な値。直径8cmの球は約268cm³なので、密度に直すと0.93g/cm³で無理がない |
| 大きさ10倍で重さ1000倍 | 体積は長さの3乗に比例する（二乗三乗の法則）。250g×1000＝250kg |
| 浮いていれば浮力が支える | アルキメデスの原理。浮いている物体では、浮力と重さがつり合っている |
| 桃から生まれるのは種 | 桃は核果。果肉は子房の壁が育ったもので、次の世代になるのは硬い「核」の中の種 |
| 猫は甘みを感じない | ネコ科は甘味受容体の遺伝子 Tas1r2 が働かない（偽遺伝子になっている）。Li ら 2005年の研究 |
| 金は水の約19倍重い | 金の密度は19.32g/cm³。10Lのバケツ1杯で約193kg、金は水に沈む |

### #2 一寸法師（`story_issunboshi.json`）
**別フック**
- 「一寸法師が大きくなると\n<都が停電>する」
- 「打ち出の小づち\n電気代<日本1年分>」
- 「一寸法師は\n{1円玉}より軽い」

**タイトル**
- YouTube：「一寸法師の体重、0.3グラム【むかしばなしにマジレス】」／「打ち出の小づち、電気代がヤバすぎる」／「一寸法師、都を停電させる」
- 概要欄の一文：「身長3センチの人間を物理で考えたら、打ち出の小づちの電気代で都が真っ暗になりました。」

**科学ネタの根拠**
| ネタ | 根拠 |
|---|---|
| 一寸＝約3cm | 1尺＝10/33 m なので一寸＝約3.03cm |
| 体重約0.3g・1円玉の3分の1 | 60kg×(3.03/170)³≒0.34g。1円玉はちょうど1g |
| 小さい体は熱が逃げやすい | 体積に対する表面積の割合は小さいほど大きい。トガリネズミなどの小型哺乳類は、体重あたりの代謝がとても高い |
| 胃酸 pH1〜2 | 空腹時の胃液は pH1〜2 程度。レモン汁は pH2 前後なので「並み」と表現した |
| 小さいほど落ちても平気 | 重さは長さの3乗、空気抵抗は2乗で効くので、小さいほど落ちる速さの上限（終端速度）が低い |
| 体重約18万倍 | 60kg÷0.34g≒17.6万 → 約18万倍 |
| E=mc²で日本の電気1年分以上 | 60kg×(3.0×10⁸m/s)²≒5.4×10¹⁸J≒1.5兆kWh（1500TWh）。日本の年間電力消費は約1000TWh弱なので「1年分以上」（約1.5年分） |

※ 平安時代に電気はないので「停電」はツッコミどころとして狙ったもの。

### 解説図の作り方（`make_zu.py`）
- 図は HTML/SVG で書いて、Chromium のヘッドレス版で 1920x1080 の PNG にする。文字を直したら `python3 make_zu.py` で作り直す（`python3 make_zu.py danmen` で1枚だけ）
- 配色はイラストに合わせた和紙・墨・朱・藍。フォントは Zen Maru Gothic（初回に `shorts/fonts/` へ取得）
- 画面の下230pxは字幕用に空けてある

### 横動画での書き出し
- `make_short.py` は台本の `"format": "landscape"` を見て 1920x1080 で書き出す（字幕は画面下、フックは中央）。画像生成も 16:9 になる
- `python3 ../make_short.py story_momotaro_long.json ../out/momotaro_long.mp4` で書き出せる（初回は声147本・イラスト8枚を Gemini で生成する）
- 仮の声・仮のイラストで一部の行を書き出して、字幕の位置と図解の見え方は確認済み

## コンプライアンスの確認（今後の全作品で見る）

| 観点 | 見るところ |
|---|---|
| 属性へのレッテル | 国籍・民族・性別・年齢・体質を、ひとまとめにして笑いにしていないか（「〇〇人は〜」の言い切り） |
