# 桃太郎 長尺版のイラスト置き場

ChatGPT で描いたイラストを、次のファイル名でこのフォルダに置く（`story_momotaro_long.json` の `image_gen.image_dir` がこのフォルダを指している）。

| ファイル名 | 場面 | 使う章 |
|---|---|---|
| `scene_river.png` | 川 | 第1章 |
| `scene_house.png` | 家 | 第2章 |
| `scene_road.png` | 道 | 第3章 |
| `scene_sea.png` | 海 | 第4章 |
| `scene_feast.png` | 鬼ヶ島の宴会 | 第5章 |
| `scene_battle.png` | 戦い | オープニング・第5章 |
| `scene_treasure.png` | 宝 | 第6章 |
| `scene_home.png` | 帰郷 | 第7章 |

- プロンプトは `../illust_prompts_momotaro.md`
- 置いた絵は、自動生成より優先して使われる
- 足りない場面があると、書き出し時に Gemini で生成される（ライブラリに同じプロンプトの絵があればそれをコピー）
- 設定画（キャラクター一覧）は `sheet.png` として置いておくと、あとで描き直すときの参考になる（動画では使わない）
