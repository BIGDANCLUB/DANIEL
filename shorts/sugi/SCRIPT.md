# もしも日本からスギが消えたら？（台本 v1・約86秒）

- 型：もしもジャパン（よねあぷ型レイアウト）。ナレーションなし、効果音＋BGM。
- 主人公：秋田・山あいの町の花粉症のお父さん（50代）。冒頭でマスクをしてくしゃみ。
- 流れ：喜び（花粉が消えた）→ 逆転（山がくずれる・雪崩・木材・文化）→ 小さな逆転（ヒノキは残る）→ 10年後に戻る → くしゃみで締める。
- 物理現象：花粉のけむり（風で舞い上がる・ゆっくり落ちる）、しめ縄の落下（重力）、むき出しの斜面の土ぼこり、のこぎりの回転が止まる（慣性）、土砂くずれ（斜面と摩擦）、川の水位、雪崩（雪の板と雪けむり）、杉玉のゆれ（ふりこ）、桜の花びら（空気の抵抗）。
- 参考元との比較で直すこと：全体を暗めに（雨・雪・夕方・森の中を入れる）、正面の顔を多く、人の群れ（駅のホーム）、効果音を多く。

## 事実メモ（出典）
- スギ花粉症の有病率 38.8%（2019年 鼻アレルギー全国疫学調査。耳鼻咽喉科医とその家族が対象）→「ある調査では約4割」。
- スギ人工林 約441万ha＝人工林（約1,000万ha）の約4割（林野庁「花粉症対策 Q&A」）。東京都 約21.9万ha の約20倍。
- 国産材の素材生産量の約6割がスギ（2019年 木材需給報告書：スギ 1,274万m³／全体 2,188万m³）。
- スギ花粉症の最初の報告：1964年、栃木県日光地方（堀口・斎藤）。
- 日光杉並木：全長約37km、約1万2千本、ギネス「世界一長い並木道」（栃木県）。
- 雪崩防止林の植栽木の多くはスギ（長野県林業総合センター報告）。木の根は土をつなぎとめ、表層の土砂くずれを防ぐ（北海道森林管理局）。
- スギとヒノキの花粉は成分が似ていて、スギ花粉症の人はヒノキにも反応しやすい（割合は出典がはっきりしないので数字は出さない）。
- 縄文杉の樹齢は2千年以上〜7千年まで諸説 →「何千年も生きてきたと言われる」。
- 杉玉（酒林）：新酒ができると軒先に青い杉玉をつるす。だんだん茶色になる。
